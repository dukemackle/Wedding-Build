# Guest-site artwork: sources and licences

Every file in `public/site-art/` is a public-domain or CC0 illustration, cut out of
its paper for the guest site's Artwork option (`SITE_ART` in `src/lib/site-design.ts`).
No credit is required, but the source of each is kept here so its licence can be re-checked.
Add nothing to that folder without a row here, and only from a page that states the licence
(Public Domain Mark, PD, or CC0 — not CC-BY, not "free for personal use").

## Drawn for You Do, I Do

`boot.svg`, `saguaro.svg`, `longhorn.svg`, `anchor.svg`, `shells.svg`, `frond.svg`, `grapes.svg` and `pine.svg` are
line drawings made for the app (October 2026), owned outright. Like the engravings, they're used as a mask and
filled with the accent. The scenes in `src/components/site-scene.tsx` (mountains, waves, papel picado...) are
drawn in code the same way.
